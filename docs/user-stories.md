# User Stories

| ID | As a... | I want to... | So that... | Acceptance criteria |
|---|---|---|---|---|
| US1 | player | choose a hero class and a name | I can play with a style I like | Three classes are offered; invalid names (too short, too long, symbols) are rejected with a message and asked again |
| US2 | player | explore the dungeon room by room | the game has progress and surprise | 10 floors x 3 rooms; rooms can be monster, treasure, spring or empty; the last room is the boss |
| US3 | player | fight monsters with attack, skill, item or flee | I can make tactical decisions | Each action resolves a round; the monster answers; boss fights cannot be fled |
| US4 | player | switch my combat style at any time | I can adapt to dangerous enemies | Balanced, Aggressive and Defensive styles change damage and defense immediately |
| US5 | player | use my class skill | each class feels different | Warrior, Mage and Rogue skills behave differently; using a skill without enough mana shows an error and costs no turn |
| US6 | player | collect, sort and use items | I can recover between fights | Bag holds 8 items; a full bag leaves loot behind with a warning; items can be sorted by name or value |
| US7 | player | level up from experience | my hero grows stronger | Level-up raises stats per class and fully restores health and mana |
| US8 | player | save and continue later | I do not lose my run | Save from the exploration menu; continue from the main menu; a corrupted save shows an error instead of crashing |
| US9 | player | see a Hall of Fame | I can compare my runs | Top 10 runs persist between sessions; sortable by score, deepest floor or name |
| US10 | player | get clear feedback on wrong input | the game never crashes on typos | Non-numbers and out-of-range numbers are rejected and asked again |
