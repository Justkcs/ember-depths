# Release v1.0.0

## Features
- Three playable hero classes (Warrior, Mage, Rogue) with unique skills, level-up growth and flee chance
- Four monster types (Goblin, Skeleton Archer, Orc Brute, Ember Dragon boss) with their own attack behavior
- 10-floor procedurally generated dungeon with monster, treasure, spring and empty rooms
- Runtime-switchable combat styles (Strategy pattern)
- Generic inventory with capacity limit and sorting
- Save and continue (Java serialization)
- Persistent top-10 Hall of Fame (text file), sortable three ways
- Input validation and custom domain exceptions
- JUnit 5 test suite

## Known limitations
- Console interface only
- Single save slot
- Save files are tied to the class versions of this release
